## My process

### Built with

* HTML5 – Used to create the structure of the webpage, including the article image, learning badge, publication date, heading, description, author information, and footer.
* CSS3 – Used for styling the blog card, including colors, spacing, typography, borders, border-radius, shadows, and overall layout.
* Flexbox – Used to center the blog preview card horizontally and vertically and to align the author information.
* Google Fonts (Figtree) – Used to apply the Figtree font family to the webpage and create a clean, modern typography style.
* HSL Colors – Used for defining consistent colors for the background, text, card, and other elements.
* Responsive Design Techniques – Used viewport settings, flexible layouts, and `min-height: 100vh` to make the page adapt to different screen sizes.
* CSS Box Shadow – Used to create the distinctive shadow effect around the blog preview card.
* CSS Borders and Border Radius – Used to create the outlined card and rounded corners for the card and article image.

### What I learned

From this HTML and CSS project, I learned how to build a blog preview card component using semantic HTML structure and CSS styling. I learned how to organize different parts of a webpage using HTML elements such as `html`, `head`, `body`, `main`, `div`, `img`, `p`, and `footer`. I also understood the importance of using meta tags such as `charset` and `viewport` to make the webpage work correctly across different devices.

I learned how to add a favicon to a webpage and how to set a meaningful page title using the `title` element. I also learned how to connect external fonts from Google Fonts using `link` tags and how to use the Figtree font family throughout the webpage.

From the CSS, I learned how to create a visually appealing card design by using properties such as `background-color`, `width`, `padding`, `border-radius`, `border`, and `box-shadow`. I learned how to use HSL color values to define colors for the yellow background, black text, white card, and gray description text.

I also learned how to use Flexbox to create a flexible page layout. The `body` uses `display: flex` and `flex-direction: column`, while the `main` section uses `display: flex`, `justify-content: center`, and `align-items: center` to position the card in the center of the page. I learned how using `flex: 1` on the main section allows it to take up the available space and helps keep the footer at the bottom of the page.

Another important thing I learned was how to create the author information section using Flexbox. The `.info` class uses `display: flex` and `align-items: center` to place the author's profile image and name next to each other with consistent spacing.

I learned how to organize CSS into reusable classes such as `.card`, `.badge`, `.heading`, `.desc`, and `.info`. This makes it easier to apply specific styles to different parts of the component and keeps the CSS more organized.

I also learned how to create visual effects using CSS, such as the thick black border and offset box shadow on the card. The combination of `border: 2px solid` and `box-shadow: 8px 8px 0px` helped recreate the distinctive design of the Frontend Mentor challenge.

Overall, this project improved my understanding of creating real-world frontend components using HTML and CSS. It helped me practice Flexbox, custom fonts, HSL colors, spacing, typography, borders, shadows, responsive layouts, and organizing styles into reusable classes.
