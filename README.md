## My process

### Built with

- HTML5 – Used to create the structure of the webpage, including the QR code image, text content, main section, and footer.
- CSS3 – Used for styling the component, adding colors, spacing, typography, rounded corners, and layout design.
- Flexbox – Used to center the QR code card and create a responsive page layout.
- Google Fonts (Outfit) – Used to apply a custom font style to the webpage.
- HSL Colors – Used for defining consistent and modern color values.
- Responsive Design Techniques – Used viewport settings, flexible layouts, and min-height: 100vh to make the page adapt to different screen sizes.

### What I learned

From this complete HTML and CSS project, I learned how to build a simple and responsive QR code card component using HTML and CSS. I learned how to create the basic structure of a webpage using HTML elements like <!DOCTYPE html>, html, head, body, main, div, img, p, and footer. I understood the importance of using meta tags like charset and viewport to make the website work correctly across different devices. I learned how to add a favicon, set a webpage title, and connect external fonts from Google Fonts using link tags.

From the CSS, I learned how to style a webpage by applying background colors, custom fonts, text colors, font sizes, and font weights. I learned how to use HSL color values and how to create a clean card design with properties like width, padding, border-radius, and background-color. I also learned how to use Flexbox with properties like display: flex, flex-direction, justify-content, and align-items to center the QR card both horizontally and vertically.

I learned how to create a responsive page layout by setting min-height: 100vh and using flex: 1 to allow the main section to take available space. I also learned how to keep the footer at the bottom of the page using margin-top: auto. The project helped me understand how HTML provides the structure of a webpage while CSS controls its appearance and layout.

Additionally, I learned how to organize content into reusable classes like .card, .heading, and .desc to apply styles efficiently. I understood how images are added using the img tag and how text content can be styled separately for better design. Overall, this project improved my understanding of building real-world frontend components, using responsive layouts, connecting external resources, and creating a visually appealing user interface with HTML and CSS.
